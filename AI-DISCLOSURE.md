# AI disclosure

Grandma's Recipe Box was made for iHack 2026. This is exactly where AI was and wasn't used.

- **Code:** written with Claude (Anthropic) in Claude Code, reviewed and explained by the team.
- **Artwork:** generated with Google Gemini from the prompts in `IMAGE-PROMPTS.txt`, then cleaned up by the team. Margins were trimmed, backgrounds whitened and files shrunk with `tools/prepare-art.py`, a script written by Claude. The layout was fitted to the pictures by Claude.
- **Image prompts:** written with Claude, generated by the team.
- **Sound effects and ambient loops:** generated with code written by Claude (`tools/synth-sounds.py`); no recordings or samples were used.
- **Radio music:** provided by the team; any outside tracks are credited in `CREDITS.txt`.
- **Sample recipes:** adapted from a public-domain cookbook (Fannie Farmer's *Boston Cooking-School Cook Book*, Project Gutenberg ebook #65061).
- **The live site uses no AI model:** link reading uses recipe data that sites already publish, and photo reading runs Tesseract.js in the browser.
